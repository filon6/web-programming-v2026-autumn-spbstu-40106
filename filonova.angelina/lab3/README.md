# Лабораторная работа 3

## Задание

Вариант 10. Реализовать функцию findMedian(arr), вычисляющую медиану числового массива.


## Реализация

Функция создаёт отсортированную копию исходного массива. Для массива нечётной длины возвращается центральный элемент, для массива чётной длины возвращается среднее двух центральных элементов.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
