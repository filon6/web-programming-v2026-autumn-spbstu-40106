# Лабораторная работа 5

## Задание

Вариант 10. Создать интерактивный калькулятор с базовыми арифметическими
операциями, вычислением процентов и изменением знака числа.

## Реализация

Калькулятор реализован на React.

Поддерживаются:

- ввод чисел от 0 до 9
- сложение, вычитание, умножение и деление
- вычисление результата
- очистка
- вычисление процентов
- изменение знака числа
- отображение текущего выражения и результата

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
