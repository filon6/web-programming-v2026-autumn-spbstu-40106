# Лабораторная работа 3

## Задание

Вариант 10. Реализовать функцию `findMedian(arr)`, вычисляющую медиану числового массива.

## Реализация

Функция создаёт отсортированную копию исходного массива.

- Для массива нечётной длины возвращается центральный элемент
- Для массива чётной длины возвращается среднее двух центральных элементов
- Исходный массив не изменяется

Функция экспортируется как именованный ES module export `findMedian`.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
