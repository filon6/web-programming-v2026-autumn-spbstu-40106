# Лабораторная работа 2

## Задание

Вариант 10. Написать функцию findMissingNumber(arr), находящую пропущенное число
в массиве целых чисел от 1 до N (одно пропущено).

## Реализация

Функция вычисляет ожидаемую сумму чисел от 1 до N и вычитает из неё сумму
элементов исходного массива. Полученная разность является пропущенным числом.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
